# cc-clinic-lab · 临床试验访视采集台

数据工程产品线基线。题号前缀 `clinic-*`，默认端口 **7600**。

## 技术栈

- 后端：CherryPy + SQLite
- 前端：原生 JS SPA（顶栏薄荷绿丝带导航）
- 会话：itsdangerous 签名 Cookie
- 测试：pytest + httpx（依赖已列入 requirements）

## 登录

- 地址：`http://127.0.0.1:7600/login`
- 账号：`admin` / `123456`

## 页面

| 页面 | 能力 |
|------|------|
| 试验中心 | 中心登记、启停/观察、配额、方案版本生效 |
| 访视批次 | 开批、模拟抓取、追加访视行、合格入库、收齐/关闭 |
| 字段质控 | 按批/全量扫描、发现关闭/重开 |
| 缺口补采 | 排队、执行成功/失败、失败重试 |
| 访视对账 | 缺口/发现/补采对照、中心矩阵、审计 |
| 台参数 | 设置读写 |

## 主链

中心 → 访视批次抓取 → 质控发现 → 缺口补采 → 对账报告；设置与审计贯穿写操作。

## 收齐闸（甲路 · 切流账册）

- 徽标派生自真值：有缺口/开放发现/补采中即「未收齐」，不得硬亮假绿。
- 真值收齐后须先在「台参数 → 收齐钉定」落台：写耐久包行 + 提交档行入 `meta` 表，
  读轨切到 `cutover_book`，拒回刷开启；落定失败会说明缺口/发现/补采计数。
- 徽标亮而键号无落点（拧花）或闸已钉定时，抓取/质控扫描/合格入库/补采排队一律 409。
- 钉定走 `BEGIN IMMEDIATE` 抢锁，并发争用只有一侧成功，杜绝双成功互踩钉点。
- 乙路（双写 live_flag）未择定，两轨不并存；半修皮面（只亮徽标不写闸行）已废弃。

## 本地

```powershell
python -m venv .venv

pip install -r requirements.txt

```
